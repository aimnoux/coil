# Coil

Трекер привычек для iPhone. По функциям повторяет Android-приложение
[Loop Habit Tracker](https://github.com/iSoron/uhabits), но с нативным iOS-дизайном.
Бесплатный, без рекламы, без аккаунтов и сбора данных.

## Что умеет

**Главный экран**
- список привычек с отметками за последние дни (количество колонок подстраивается под ширину экрана);
- свайп по заголовку с датами листает в прошлое, кнопка «Today» возвращает к сегодняшнему дню;
- кольцо силы привычки у каждой строки;
- отметка касанием (или долгим нажатием, если включено в настройках): выполнено → пропуск → не выполнено → нет отметки;
- для измеримых привычек ввод значения с кнопками ±;
- сортировка (вручную, по названию, цвету, силе, статусу), фильтры «Показать архив» и «Скрыть выполненные»;
- изменение порядка перетаскиванием, свайпы и контекстное меню: изменить, в архив, удалить;
- режим выбора: несколько привычек сразу в архив, сменить им цвет или удалить.

**Типы привычек и расписания**
- «Да/нет» и измеримые (единица измерения, цель «не меньше» или «не больше», период: день, неделя или месяц);
- частота: каждый день, раз в N дней, N раз в неделю, N раз в месяц, своя (N раз за M дней);
- автоматические отметки: если цель на период уже выполнена, остальные дни периода засчитываются (полупрозрачная галочка, как в Loop).

**Статистика привычки**
- обзор: сила привычки, изменение за месяц и год, сколько раз выполнено, текущая серия;
- прогресс к цели за день, неделю, месяц, квартал и год (для измеримых);
- график силы привычки и гистограмма истории с группировкой по дням, неделям, месяцам, кварталам и годам;
- календарь-сетка за всю историю, где каждый день можно изменить нажатием;
- лучшие серии;
- частота выполнения по дням недели за последние 12 месяцев;
- заметки к привычке и **заметки к отдельным дням** (удерживайте день в календаре или пишите при вводе значения).

**Сила привычки** — экспоненциальное скользящее среднее, как в Loop: повторения её поднимают, пропуски опускают,
но несколько пропущенных дней после долгой серии не обнуляют прогресс. Скорость затухания зависит от частоты,
поэтому еженедельная привычка не слабеет в дни, когда её не нужно делать. Пропуски (skip) силу не меняют.

**Напоминания** для каждой привычки: время и дни недели. Прямо из уведомления можно отметить привычку
или попросить напомнить позже (интервал задаётся в настройках).

**Данные**
- экспорт в CSV (список привычек и таблица отметок; для одной привычки — со своего экрана);
- полная резервная копия в JSON и восстановление из неё;
- **импорт из Loop Habit Tracker**: в Loop на Android откройте «Настройки» → «Экспорт полной копии»
  и импортируйте полученный `.db` файл в Coil («Настройки» → «Импорт копии»).

**Siri и Shortcuts**: «Отметить привычку» и «Статус привычки» доступны в приложении «Команды» и через Siri.

**Платные функции** (нужен Apple Developer Program, $99/год), уже реализованы и включаются флагом:
- синхронизация через iCloud — [docs/ICLOUD.md](docs/ICLOUD.md);
- виджеты для экрана «Домой» и экрана блокировки — [docs/WIDGETS.md](docs/WIDGETS.md).

**Прочее**: светлая и тёмная темы, выбор первого дня недели, сегодняшний день слева или справа,
русская и английская локализация, VoiceOver.

## Разработка

Нужны Xcode 26+ и [XcodeGen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`).

```bash
xcodegen                 # сгенерировать Coil.xcodeproj
open Coil.xcodeproj
```

Файл проекта генерируется из [project.yml](project.yml) и не хранится в git. После добавления файлов
снова запустите `xcodegen`.

Варианты сборки:

```bash
xcodegen                                      # бесплатный Apple ID: без iCloud и виджетов
COIL_WIDGETS=true xcodegen                    # + виджеты (нужен платный аккаунт)
COIL_ICLOUD=true COIL_WIDGETS=true xcodegen   # всё, для App Store
```

Тесты:

```bash
xcodebuild -scheme Coil -destination 'platform=iOS Simulator,name=iPhone 18 Pro' -derivedDataPath build test
```

Аргументы запуска для отладки:
- `-sampleData` — демо-привычки во временной базе в памяти (реальные данные не трогаются);
- `-seedSampleData` — заполнить демо-привычками пустую реальную базу (например, чтобы посмотреть виджеты);
- `-screenshotHabit N`, `-screenshotEditor YES`, `-screenshotSelect YES` — сразу открыть нужный экран
  (только Debug, для скриншотов).

Скрипты:
- `swift scripts/make-icon.swift Coil/Resources/Assets.xcassets/AppIcon.appiconset` — перерисовать иконку;
- `python3 scripts/localize.py` — пересобрать `Localizable.xcstrings` из строк, извлечённых при сборке
  (русские переводы лежат в самом скрипте).

## Структура

```
Coil/
  App/          точка входа, AppDelegate (уведомления), Siri/Shortcuts
  Domain/       чистая логика: дни, частота, сила привычки, серии, история (покрыта тестами)
  Model/        SwiftData-модели (совместимы с CloudKit), хранилище
  Intents/      App Intents: общие для приложения и виджетов
  Services/     напоминания, CSV, резервные копии, импорт из Loop
  Support/      настройки, форматирование, демо-данные
  Views/        экраны SwiftUI
Widgets/        расширение с виджетами (включается флагом)
CoilTests/      тесты (Swift Testing)
docs/           инструкции и материалы для App Store
scripts/        иконка и локализация
```

## Лицензия и Loop

Coil написан с нуля. Код, иконки и графика Loop (GPLv3) не используются: повторены только
функции и поведение. Импорт `.db` основан на открытом формате базы данных Loop.
