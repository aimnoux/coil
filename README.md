# Coil

Трекер привычек для iPhone. По функциям повторяет Android-приложение
[Loop Habit Tracker](https://github.com/iSoron/uhabits), но с нативным iOS-дизайном.
Бесплатный, без рекламы, без аккаунтов и сбора данных.

## Что умеет

**Главный экран**
- привычки с отметками за последние дни; свайп по датам листает в прошлое;
- **группы** («Утро», «Здоровье»…) — сворачиваемые разделы списка;
- у каждой привычки **иконка** в кольце силы и строка статуса: челлендж, пауза, дни без срыва, идущий таймер;
- отметка касанием (или долгим нажатием): выполнено → пропуск → не выполнено; встряхните, чтобы отменить;
- сортировка, фильтры, режим выбора: в архив, сменить цвет, удалить несколько привычек сразу;
- **отмена** удаления, архивации и других действий плашкой «Отменить».

**Создание привычки**
- **146 шаблонов** в 15 темах (здоровье, спорт, питание, сон, осознанность, обучение, продуктивность, финансы,
  отношения, дом, творчество, забота о себе, «бросить привычку», челленджи) с поиском, на двух языках;
- типы: «да/нет», измеримая (единицы, цель «не меньше/не больше», день/неделя/месяц/раз в N дней), **«бросить»**;
- частота: каждый день, раз в N дней, N раз в неделю или месяц, своя;
- **рабочие дни**: все, будни, выходные или любые дни недели; в остальные дни привычка отдыхает — серия и сила
  не страдают, напоминаний нет, а если всё-таки сделали, это засчитывается;
- **учёт времени**: секундомер или таймер с историей сессий;
- **челлендж** на 7–365 дней; **несколько напоминаний в день**; связь с **Apple Health**.

**Экран привычки**
- обзор силы, цель, графики силы и истории, календарь (касание — изменить, удержание — заметка);
- серии, частота по дням недели, заметки по дням;
- карточки: **без срыва** (для «бросить»), **челлендж**, **таймер** с историей, **достижения**, **паузы**.

**Таймер**: секундомер или обратный отсчёт; учитывается только длительность, сессии короче минуты не
сохраняются; длительность можно поправить (если забыли остановить) или добавить вручную двумя ползунками —
часы и минуты с шагом 15; значение дня — сумма сессий, от часа показывается как «2h30m»; уведомление по окончании, даже если
приложение закрыто.

**Пауза и режим отпуска**: дни на паузе не снижают силу и не рвут серию, напоминания не приходят. Пауза для одной
привычки или для всех сразу.

**Умные напоминания**: несколько в день, не приходят, если привычка уже выполнена или на паузе. Из уведомления
можно отметить привычку или отложить напоминание.

**Достижения**: серии (3–365 дней), количество выполнений, сила привычки, идеальный месяц, возвращение после
перерыва, челленджи, общие вехи. Точная дата получения и поздравление в момент получения.

**Статистика**: итоги недели и месяца (процент выполнения, сравнение с прошлым периодом, лучшая привычка, лучший
день недели, учтённое время), общая тепловая карта всех привычек за год, награды.

**Данные**: CSV, полная резервная копия (с группами, паузами, сессиями), **автобэкапы** по расписанию
(день/неделя/месяц, хранить последние N) в «Файлы» и iCloud Drive, **импорт из Loop Habit Tracker**.

**Siri, «Команды», виджеты, Пункт управления** (виджеты и кнопка — с платным аккаунтом, см. ниже).

**Оформление**: пастельная палитра, SF Pro Rounded, светлая и тёмная темы, русский и английский, крупный шрифт,
VoiceOver.

**Платные возможности** (нужен Apple Developer Program), уже реализованы и включаются флагами:
- синхронизация через iCloud — [docs/ICLOUD.md](docs/ICLOUD.md);
- 7 виджетов и кнопка Пункта управления — [docs/WIDGETS.md](docs/WIDGETS.md);
- Apple Health (может заработать и бесплатно — попробуйте) — [docs/HEALTH.md](docs/HEALTH.md).

## Разработка

Нужны Xcode 26+ и [XcodeGen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`).

```bash
xcodegen                 # сгенерировать Coil.xcodeproj
open Coil.xcodeproj
```

Файл проекта генерируется из [project.yml](project.yml) и не хранится в git. После добавления файлов
снова запустите `xcodegen`.

Варианты сборки:

```bash
xcodegen                                                    # бесплатный Apple ID
COIL_HEALTH=true xcodegen                                   # + Apple Health
COIL_ICLOUD=true COIL_WIDGETS=true COIL_HEALTH=true xcodegen # всё, для App Store
```

Тесты (юнит-тесты и UI-тесты; на GitHub они запускаются автоматически, см. `.github/workflows/ci.yml`):

```bash
xcodebuild -scheme Coil -destination 'platform=iOS Simulator,name=iPhone 18 Pro' -derivedDataPath build test -only-testing:CoilTests
xcodebuild -scheme Coil -destination 'platform=iOS Simulator,name=iPhone 18 Pro' -derivedDataPath build test -only-testing:CoilUITests
```

Аргументы запуска для отладки:
- `-sampleData` — демо-привычки во временной базе в памяти (реальные данные не трогаются);
- `-seedSampleData` — заполнить демо-привычками пустую реальную базу (например, чтобы посмотреть виджеты);
- `-screenshotHabit N`, `-screenshotEditor YES`, `-screenshotSelect YES` — сразу открыть нужный экран
  (только Debug, для скриншотов);
- `-debugReminders YES` — вывести в консоль все запланированные напоминания;
- `-seedHealth YES` (сборка с `COIL_HEALTH=true`) — записать в «Здоровье» симулятора неделю шагов и привязанную привычку;
- `-renderWidgets YES` (сборка с `COIL_WIDGETS=true`) — отрисовать все виджеты с реальными данными в
  `Documents/WidgetGallery` приложения.

Сайт с политикой конфиденциальности опубликован: https://aimnoux.github.io/coil-app/privacy.html
(`scripts/publish-site.sh [email]` переопубликует его; без email контактом служат GitHub Issues).

Скрипты:
- `python3 scripts/make_icon.py Coil/Resources/Assets.xcassets/AppIcon.appiconset` — перерисовать иконку (нужны numpy и Pillow);
- `python3 scripts/localize.py` — пересобрать `Localizable.xcstrings` из строк, извлечённых при сборке
  (русские переводы лежат в самом скрипте).

## Структура

```
Coil/
  App/          точка входа, AppDelegate (уведомления), Siri/Shortcuts
  Domain/       чистая логика: дни, частота, сила привычки, серии, история (покрыта тестами)
  Model/        SwiftData-модели (совместимы с CloudKit), хранилище
  Intents/      App Intents: общие для приложения и виджетов
  Services/     напоминания, таймер, Health, CSV, бэкапы, автобэкапы, импорт из Loop
  Support/      настройки, шаблоны, каталог иконок, отмена действий, демо-данные
  Views/        экраны SwiftUI
Widgets/        расширение с виджетами и кнопкой Пункта управления (включается флагом)
CoilTests/      юнит-тесты (Swift Testing), включая тесты производительности
CoilUITests/    UI-тесты основных сценариев
site/           сайт: политика конфиденциальности, поддержка (публикуется scripts/publish-site.sh)
docs/           инструкции и материалы для App Store
scripts/        иконка и локализация
```

## Лицензия и Loop

Coil написан с нуля. Код, иконки и графика Loop (GPLv3) не используются: повторены только
функции и поведение. Импорт `.db` основан на открытом формате базы данных Loop.
