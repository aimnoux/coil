# Apple Health

Привычку можно связать с метрикой из приложения «Здоровье». Тогда дни заполняются сами:

| Метрика | Что берётся за день |
|---|---|
| Шаги | сумма шагов |
| Дистанция ходьбы и бега | километры |
| Активная энергия | ккал |
| Минуты упражнений | минуты (кольцо «Упражнения») |
| Часы с разминкой | сколько часов вы вставали |
| Пролёты лестниц | этажи |
| Минуты осознанности | сумма сессий осознанности |
| Сон | часы сна, засчитываются на утро пробуждения |
| Вода | литры |
| Тренировки | количество тренировок |

- **Измеримая привычка** получает значение дня («8 123 шагов»).
- **Привычка «да/нет»** отмечается, когда значение дошло до порога из настроек привычки.
- **Ручные правки главнее:** если вы изменили день сами, синхронизация его не трогает.
- Данные читаются при каждом открытии приложения за последние 30 дней. Coil ничего не записывает в «Здоровье».

## Как включить

HealthKit — отдельная возможность приложения, поэтому она включается флагом:

```bash
COIL_HEALTH=true xcodegen                                  # только Health
COIL_HEALTH=true COIL_ICLOUD=true COIL_WIDGETS=true xcodegen  # всё вместе
```

Флаг добавляет право `com.apple.developer.healthkit`, текст запроса доступа
(`NSHealthShareUsageDescription`) и флаг компиляции `HEALTHKIT`. Без флага раздел Apple Health
в редакторе привычки не показывается.

HealthKit может работать и с бесплатным Apple ID: попробуйте собрать с `COIL_HEALTH=true`.
Если Xcode скажет, что Personal Team не поддерживает HealthKit, остаётся только платный аккаунт.

В App Store Connect при включённом Health в анкете конфиденциальности по-прежнему можно указать
«Данные не собираются»: данные о здоровье читаются только на устройстве и никуда не отправляются.
Это же сказано в политике конфиденциальности (`site/privacy.html`).
