# Установка на свой iPhone бесплатно

Без Apple Developer Program приложение можно поставить на свой iPhone через Personal Team.
Работает всё, кроме iCloud-синхронизации и виджетов.

## Один раз

1. Xcode → Settings → Accounts → «+» → войдите под своим Apple ID.
2. Сгенерируйте проект и откройте его:
   ```bash
   cd ~/Projects/GitHub/coil
   xcodegen
   open Coil.xcodeproj
   ```
3. В Xcode выберите таргет **Coil** → вкладка **Signing & Capabilities** → **Team**: ваш Apple ID (Personal Team).
   Если Xcode скажет, что Bundle ID занят, поменяйте его на свой (например, `com.maxouni.coil.dev`).
4. Подключите iPhone кабелем, выберите его вверху окна Xcode и нажмите **Run** (⌘R).
5. На iPhone:
   - «Настройки» → «Конфиденциальность и безопасность» → **Режим разработчика** → включить
     (телефон перезагрузится);
   - «Настройки» → «Основные» → «VPN и управление устройством» → ваш Apple ID → **Доверять**.

После этого iPhone можно подключать к Xcode по Wi-Fi (Window → Devices and Simulators → Connect via network).

## Раз в 7 дней

Подпись бесплатного аккаунта действует 7 дней. Когда приложение перестанет открываться, снова нажмите **Run**
в Xcode. Если ставить поверх, не удаляя приложение, данные сохраняются.

Совет: время от времени делайте резервную копию («Настройки» → «Экспорт полной копии»), например в Файлы.

## Перенос данных из Loop

1. В Loop на Android: «Настройки» → «Экспорт полной копии» → сохраните `.db` файл.
2. Перекиньте файл на iPhone (AirDrop не работает с Android, удобнее всего через Telegram, облако или почту)
   и сохраните его в «Файлы».
3. В Coil: «Настройки» → «Импорт копии» → выберите файл.
