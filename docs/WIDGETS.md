# Виджеты

Виджеты уже написаны (папка [Widgets](../Widgets)), но выключены по умолчанию. Виджету нужен доступ к базе
приложения через **App Group**, а бесплатный Apple ID (Personal Team) не может подписать App Group.
Если включить виджеты без платного аккаунта, Xcode не сможет установить приложение на iPhone.

## Какие есть виджеты

| Виджет | Размеры | Что показывает |
|---|---|---|
| **Habit** | маленький, круглый и прямоугольный на экране блокировки | одна привычка (выбирается в настройках виджета): сила, серия, кнопка «выполнено сегодня» |
| **Habits** | средний и большой | 3 или 7 привычек с отметками за последние дни и кнопкой отметки за сегодня |
| **Habit Strength** | средний | график силы выбранной привычки за последние 16 недель, процент и серия |
| **Streak** | маленький, круглый и строка на экране блокировки | серия дней подряд (для «бросить» — дни без срыва) |
| **Progress** | маленький, круглый на экране блокировки | прогресс измеримой привычки к цели за сегодня |
| **Heatmap** | средний и большой | общая тепловая карта всех привычек за последние недели |
| **Check Off Habit** | Пункт управления и экран блокировки (iOS 18) | кнопка-переключатель «выполнено сегодня» для выбранной привычки |

Кнопки работают без открытия приложения (интерактивные виджеты). Для измеримой привычки
нажатие открывает приложение, потому что нужно ввести значение.

## Как включить

1. Оплатите Apple Developer Program и укажите `DEVELOPMENT_TEAM` в [project.yml](../project.yml).
2. Сгенерируйте проект:
   ```bash
   COIL_WIDGETS=true xcodegen            # только виджеты
   COIL_ICLOUD=true COIL_WIDGETS=true xcodegen   # виджеты и iCloud
   ```
3. В Xcode: Signing & Capabilities → **App Groups** → убедитесь, что `group.com.maxouni.coil` отмечена
   у таргетов **Coil** и **CoilWidgets**.

При первом запуске с App Group приложение само перенесёт существующую базу в общую папку,
и данные не потеряются.

## Как это устроено

- [Persistence.swift](../Coil/Model/Persistence.swift): база лежит в контейнере App Group, если он доступен.
- [HabitIntents.swift](../Coil/Intents/HabitIntents.swift): `ToggleHabitIntent` отмечает привычку из виджета,
  `SelectHabitIntent` выбирает привычку для виджета.
- Приложение обновляет виджеты после каждого сохранения (`ModelContext.didSave`), а виджеты
  обновляются сами сразу после полуночи.

## Ограничения

- Виджет открывает общую базу без iCloud-синхронизации (флаг `ICLOUD` действует только на приложение).
  Отметка, сделанная в виджете, попадает в iCloud при следующем запуске приложения: SwiftData отслеживает
  историю изменений общей базы и отправляет их при синхронизации.
- Если виджет добавлен до первого запуска приложения с App Group, он показывает пустое состояние
  и не создаёт базу. Это нужно, чтобы приложение могло перенести существующие данные в общую папку.
