Moving from Loop Habit Tracker

In Loop on Android open Settings → Export full backup, move the .db file to your iPhone, then in Coil open Settings → Import Backup.

Backups

Coil can back up automatically (Settings → Automatic Backups). Backups appear in the Files app under On My iPhone → Coil → Backups.

Переход с Loop Habit Tracker

В Loop на Android откройте Настройки → Экспорт полной копии, перенесите файл .db на iPhone и в Coil откройте Настройки → Импорт копии.

Резервные копии

Coil умеет делать копии автоматически (Настройки → Автобэкапы). Они лежат в приложении «Файлы»: На iPhone → Coil → Backups.
